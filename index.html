About Pflix

Pflix is a free and open-source media finder inspired by StreamIt, powered by a custom Cloudflare Workers API. Pflix does not host, store, or stream any content directly; all streams are embedded via public third-party providers.

AdBlock Recommendation: Embedded players may contain third-party popups. We strongly recommend using AdBlock or uBlock Origin.

Server Status: Check live latency badges next to server names on the player to pick the fastest responding mirror.
